# M1 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Swift package with the safety-critical core (Shell, DiskSize, PathGuard), the shared config, and the built-in path catalog, plus a `phew` CLI that can print its version and list targets.

**Architecture:** One SwiftPM package. `PhewCore` library holds everything testable; `phew` executable is a thin swift-argument-parser layer over it. No deletion code in M1 (that is M2); M1 only measures and validates.

**Tech Stack:** Swift 6 (tools 6.0, strict concurrency), macOS 14+, swift-argument-parser `from: "1.5.0"`, Swift Testing.

**Spec:** `docs/plan.md` (sections 2, 4, 5, 6, 8, 10, 12, 14)

## Global Constraints

- Minimum macOS 14, Swift 6 language mode. Only dependency: swift-argument-parser.
- Bundle id `com.dikaputra.phew`. Repo URL `https://github.com/dika-putra/phew`. Author "Dika Putra".
- Config path `~/.config/phew/config.json`. Default `dormantDays` 14, `lowSpaceAlert` `{ "enabled": true, "thresholdGB": 20 }`, `projectRoots` empty.
- Tiers: `regenerates`, `redownload`, `dataLoss`. Flags: `heavy`, `needsAdmin`, `needsFDA`, `optIn`.
- Processes start with the working directory set to `$HOME`.
- Sizes are allocated sizes, hard links counted once, mounted volumes not walked.
- Tests use temp folders only. Tests that call real tools only run with `PHEW_REAL_TOOLS=1`.
- After every task: update `docs/progress.md` (see Task 0) and commit it with the task.

## Review Focus

1. A malformed `config.json` (bad JSON, wrong types): load must not crash and must not overwrite the user's file; it returns defaults plus an issue. Test in Task 5.
2. Paths with `~`, trailing `/`, `..`, or a symlinked parent: PathGuard must judge the real location, so `~/Library/Caches/../../` is refused. Test in Task 4.
3. A folder that cannot be read (permission denied) during sizing: skip it, count it as unreadable, never throw for the whole target. Test in Task 3.
4. A project root that is a symlink to another volume: stored resolved, accepted as a root. Test in Task 5.
5. A custom target pointing at `~`, `/`, or `/Users`: rejected with an issue, other custom targets still load. Test in Task 5.

### Task 4: PathGuard

**Files:**
- Create: `Sources/PhewCore/Services/PathGuard.swift`, `Tests/PhewCoreTests/PathGuardTests.swift`

**Interfaces:**
- Produces: `public struct PathGuard: Sendable { init(allowedRoots: [URL], home: URL = FileManager.default.homeDirectoryForCurrentUser); func check(_ url: URL) throws(PathGuardError) }`, `public enum PathGuardError: Error, Equatable { case forbidden(String), outsideRoots(String), escapesRoot(String) }`, and `public static func isForbidden(_ url: URL, home: URL) -> Bool` (reused by Config in Task 5).

Rules (spec section 6, rules 2 and 10):
- Forbidden: `/`, `home`, any ancestor of `home`, `/System` and below, `/Library` and below except `/Library/Developer/CoreSimulator/Caches` and below.
- The path's parent is resolved with `resolvingSymlinksInPath()`; the last component is not resolved (deleting a link removes the link). The resolved path must equal or be inside one of `allowedRoots` (roots also resolved), else `outsideRoots`. If the unresolved path is inside a root but the resolved one is not, `escapesRoot`.

- [ ] **Step 1: Write the failing tests** (home and roots are temp dirs)

```swift
@Test func allowsPathInsideRoot()            // root/a/b passes
@Test func allowsRootItself()                // root passes
@Test func refusesHomeAndRootAndAncestors()  // home, "/", home.deletingLastPathComponent() -> .forbidden
@Test func refusesSystemAndLibrary()         // "/System/Library", "/Library/Caches" -> .forbidden; "/Library/Developer/CoreSimulator/Caches/dyld" is not forbidden by isForbidden
@Test func refusesDotDotEscape()             // root.appending(path: "a/../../x") -> .outsideRoots
@Test func refusesSymlinkedParentEscape()    // root/link -> outside dir; root/link/file -> .escapesRoot
@Test func allowsSymlinkAsLastComponent()    // root/link (pointing outside) itself passes
```

- [ ] **Step 2: Run `swift test --filter PathGuardTests`.** Expected: FAIL.
- [ ] **Step 3: Implement** as specified above. Normalize with `standardizedFileURL` before comparing; compare by path components, not string prefix (`/a/bc` is not inside `/a/b`).
- [ ] **Step 4: Run `swift test --filter PathGuardTests`.** Expected: PASS.
- [ ] **Step 5: Update progress, commit** `Add PathGuard`.
