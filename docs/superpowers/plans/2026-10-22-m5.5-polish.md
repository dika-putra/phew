# M5.5 UI Polish and Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the menu bar app in line with the macOS HIG (hit targets, font sizes, contrast, spacing), add the small features agreed in the UI review, and give Phew its logo (app icon, menu bar icon, README banner).

**Architecture:** Model changes live in `AppModel` and `Summary` and are unit tested. View changes are checked with `PHEW_SNAPSHOT` PNGs and a short grep check for spacing and fonts. AppKit changes (right-click menu, shortcuts, popover animation) and the logo are checked by the user. The logo is drawn in code: one Swift script writes the `.icns` and the banners, and the menu bar icon is an `NSImage` template drawn at runtime, so no asset catalog is needed.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Swift Testing, `iconutil`.

**Spec:** the UI review decisions (Q1 to Q25), recorded in `docs/progress.md` under "M5.5 decisions" (Task 0), plus `docs/plan.md` for the app.

## Global Constraints

- macOS 14+. English UI only. No new dependencies.
- Spacing values in `Sources/PhewApp`: only 4, 8, 12, 16, 24 (and `12 + indent`).
- Text that carries information uses `.subheadline` (11 pt) or larger; badges use `.caption` (10 pt, HIG minimum).
- Icon-only buttons have a 28×28 pt hit area.
- Badge text in light mode has a contrast ratio of at least 4.5:1 against its tinted background.
- Logo concept I: a `>` chevron and a `_` cursor whose end curls up like a breath of air. App icon: background `#1E2229`, lines `#7CF5C8`. Menu bar: template image, chevron and curl only.
- Nothing about cleaning behaviour changes, except that Quick clean leaves out items the user unticked.

## Review Focus

1. A user unticks a preselected item, then that item disappears after a clean and comes back on the next scan: it must stay unticked (the kept list holds ids, not items). Test in Task 1.
2. A group where every item is locked or needs Full Disk Access: the group checkbox is disabled, not stuck "on". Test in Task 1.
3. Return on the confirm screen when the plan has a data-loss item must not clean. Covered by giving that button no default shortcut (Task 2) and checked by the user in Task 4.
4. Right-click on the menu bar icon while a clean runs: Refresh is disabled (the model already ignores it) and Quit asks nothing but the clean stops; the menu item says so. Checked in Task 4.
5. The kept list holds ids of items that no longer exist (a deleted project): they stay until the user removes them, and Settings shows the raw id when no title is known. Test in Task 1 (`keptTitleFallsBackToID`).

### Task 1: Model: sorting, group selection, kept items, last clean, scan stage

**Files:**
- Modify: `Sources/PhewCore/Scan/Summary.swift`, `Sources/PhewApp/AppModel.swift`, `Sources/PhewApp/Snapshots.swift` (scan signature)
- Test: `Tests/PhewCoreTests/SummaryTests.swift` (existing file; create if missing), `Tests/PhewAppTests/AppModelTests.swift`

**Interfaces:**
- `Summary.init(_ items: [Item], kept: Set<String> = [])`: `quickClean` and `reclaimable` leave out kept ids. `byTier`, `total`, `groups` unchanged.
- `AppModel`:
  - `func items(in group: String) -> [Item]`: sorted by `bytes`, largest first.
  - `func isSelectable(_ item: Item) -> Bool`: false for `.unreadable` and `.locked`.
  - `func toggleAll(_ items: [Item])`: selects every selectable item, or clears them all when all are selected. `toggleProject(_:)` calls it with `projectItems(root)`.
  - `func selectionState(_ items: [Item]) -> Checkbox.State`: `.off`, `.on` or `.mixed` over the selectable items; `.off` when none is selectable.
  - `private(set) var kept: Set<String>`: stored in `defaults` under `"keptItems"` as `[String]`. Every selection change goes through one private `setSelected(_ ids: some Sequence<String>, _ on: Bool)`: unticking an item whose `preselected` is true inserts its id into `kept`, ticking removes it. `toggle`, `toggleAll`, `toggleProject` use it. Clean (`apply`) does not touch `kept`.
  - `func unkeep(_ id: String)`: removes from `kept` (Settings).
  - `defaultSelection` leaves out kept ids. `summary` passes `kept`.
  - `func keptTitle(_ id: String) -> String`: the item's `target.title` from the snapshot, else the id.
  - `struct LastClean: Codable, Equatable { let freed: Int64; let date: Date }` and `private(set) var lastClean: LastClean?`, stored in `defaults` under `"lastClean"`, written in `confirm()` after `apply` with `receipt.measuredTotal` and `.now`, only when `measuredTotal > 0`.
  - `private(set) var scanStage: String?`: non-nil only while scanning.
  - The `scan` init parameter becomes `@escaping @Sendable (@escaping @Sendable (String) -> Void) async -> ScanSnapshot`. `liveScan(progress:)` reports, in order: `"Caches and build folders"`, `"Project folders"` (only with roots), `"Docker, simulators and versions"` (before awaiting the tool scan).
