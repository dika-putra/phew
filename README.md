# Phew

Menu bar app and CLI for macOS that frees disk space taken by developer files you can rebuild or download again: build output, package caches, SDK and toolchain versions, simulators and emulators, Docker data.

Status: planning. See [docs/plan.md](docs/plan.md). The bash script it replaces is in [docs/reference/everclean.sh](docs/reference/everclean.sh).
